# Lumen Store

Official app store of **Lumen Technologies Co.**

Live site: https://mhmahdavi1391.github.io/VR/

Drop packages into the `files/` folder.

- `.apk` / `.aab` / `.exe` / `.msi` and Quest Helper packs appear as Apps
- Other files appear under Files
- Known products get titles and descriptions in FA / EN / RU inside `app.js`

Theme: corporate Microsoft / Xbox / Sony / Dell style. Dark surface, Fluent blue accent.
