# LTC VR

**LTC VR** is the VR platform and public repository of **Lumen Technologies Co.**, providing VR-related files, tools, and services.

The project also includes **LTC Quest Helper**, a Windows utility designed to make managing Meta Quest and other Android/ADB devices easier.

---

## LTC Quest Helper

**LTC Quest Helper** is a lightweight Windows tool for managing Meta Quest headsets and other Android devices through ADB.

It runs directly on Windows and does not require Python or a separate runtime.

### Features

* USB and Wi-Fi ADB device connection
* Device connection status
* Battery and storage information
* Device model and Android version
* APK installation
* OBB and Data file management
* APK backup with associated OBB/Data files
* ADB file manager
* Access to Android Settings
* Date and time management
* MTP controls
* ADB reset
* ADB authorization/key management
* Persian, English, and Russian interface

### Requirements

* Windows
* A Meta Quest or compatible Android/ADB device
* USB debugging enabled when using ADB
* Google Android SDK Platform-Tools (`adb`)

The helper uses the official Android Debug Bridge provided by Google.
